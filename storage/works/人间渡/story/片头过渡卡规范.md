# 片头过渡卡规范

> 《人间渡》· 成片规范 | 适用范围：全部 24 集及后续季
> 目的：解决单元与单元之间的「硬切」，为每集提供一个统一的过渡态，承载「单元名 + 集名 + 集数」的剧集元信息。

## 一、为什么需要

每个单元结束是「硬切」——观众上一秒还泡在「叶生可曾活过」的悲剧里，下一秒就被丢进《小翠》的全新故事、全新鬼，情绪没有落地就被拉走。

片头过渡卡的作用：**在每集开场插入一个 2~3 秒的黑场呼吸口，用一张水墨标题卡宣告「这是第几集、属于哪个单元、这一集叫什么」**。单元名一换，观众自然感知「新故事开始了」，无需旁白或额外字幕。

## 二、卡片内容（三层信息）

每集片头卡固定呈现三层：

```
        （水墨晕染背景）

     单元名（小字）：小翠
     集名（大字）：报恩
     角标：第 3 集
```

- **单元名**（小字）——篇章名，如叶生、小翠、公孙九娘、王六郎、婴宁、连城、香玉、侠女、田七郎、孤灯、渡人、阿离。
- **集名**（大字）——本集剧名，如衣锦还乡、可曾活过、怎么忘了、渡自己。
- **第 X 集**（角标）——全集序号。

三层一次给全：观众既知道「这是第几集」，也知道「换没换故事」。

## 三、节奏与时长的两个档位

| 场景 | 时长 | 说明 |
| --- | --- | --- |
| 单元首集（问诊篇）片头 | 约 3 秒 | 单元名首次出现，给足「新篇章」的仪式感 |
| 单元次集（了结篇）片头 | 约 2 秒 | 同单元延续，快速进入，不拖节奏 |

150 秒一集的竖屏短剧，片头最长不超过 3 秒。

## 四、视觉样式

1. **黑场起**——上一集尾钩子的情绪先落空一瞬。
2. **水墨滴入、晕染**——晕开一片浅色，与全剧「不响的铃、如烟散开、水墨晕染」的视觉气质统一。
3. **单元名先浮现（小字），集名后浮现（大字），角标随集名出现**。
4. **停留约 0.5 秒，整体淡出**。
5. 淡出后直接进入该集已有的 0~15 秒冲击钩子（各集已写好的开场）。

不使用任何说明性旁白，卡上只有「单元名、集名、集数」三样。

## 五、与「无字幕」规则的关系（重要）

全剧规则是「剧情信息无字卡、无旁白」——心结、身份、生死一律由画面承载。片头过渡卡**不违反这条规则**，因为：

- 标题卡报的是**剧集元信息**（第几集、叫什么），不是剧情信息；
- 它不解释任何剧情，不替代画面叙事；
- 类比动画/剧集每话的「标题卡」，属于片头设计，不属于剧情字幕。

剧情内仍严守「无字卡、无旁白」：叶生已死靠「无影 + 棺材」，小翠心结靠「舍不得二字」，九娘含怨靠「如雾散开、不是安息」——这些都不因为有了片头卡而放松。

## 七、出片衔接

- 每集正片之前，先渲染这张片头卡，再接该集 `epNN.md` 的开场动作。
- 卡上文字从本表取，不另设字段；`epNN.md` 顶部已有的 `# 第 X 集 · 集名` 与 `单元 X《单元名》` 即标题卡的数据源。
- 单元切换（如 第2集→第3集、第4集→第5集）时，单元名变化即完成「换篇章」的过渡，不加旁白、不加额外转场说明。
