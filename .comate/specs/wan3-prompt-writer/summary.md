- 创建个人 Skill：`/Users/zhangzhiyu/.comate/skills/wan3-prompt-writer/SKILL.md`
- 创建测试用例：`/Users/zhangzhiyu/.comate/skills/wan3-prompt-writer/evals/evals.json`
- 固化 Wan3 模式：`t2v`、首帧/I2VA、首尾帧/FL2VA、尾帧/L2VA、全能参考/Ref2VA。
- 固化首帧/尾帧与额外参考图互斥规则。
- 固化真实 `@图片` 契约：每个引用必须对应真实传给 Wan3 的 URL、上传资源 ID 或实际附带的本地文件。

- 固化连续动作因果链：承接状态、触发、方向、轨迹、接触/受力、位移、反应、环境变化和结束状态。
- 固化镜头参数、结束状态、音效和无台词镜头的输出规则。
- 加入无效图片引用的拒绝示例，防止把文件名伪装成真实参考图。

## 已知限制

- 当前完成的是规则 Skill 和静态测试用例，未运行 Comate 对照评测器或浏览器可视化评审流程。
- Skill 不负责上传图片、调用 Wan3 API 或生成图片文件；调用方仍需提供真实媒体输入和网页预览映射。
- 如果上游图片生成服务不可用，Skill 会准确标记引用缺失，但不会伪造可用图片 URL 或资源 ID。
