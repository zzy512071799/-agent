- [x] Task 3: 固化真实 `@图片` 引用规则
    - 3.1: 每个 `@图片N` 必须对应真实传递给 Wan3 的图片 URL、上传资源标识或实际附带的本地文件
    - 3.2: Prompt 编号、Wan3 媒体数组顺序、网页预览顺序保持一致

    - 3.5: 网页中的 `@图片N` 必须可点击，并能正常预览对应图片
    - 3.6: 图片缺失、加载失败、内容不一致或无法真实传递时标记为无效并停止伪造引用

    - 4.4: 连续动作写清承接状态、触发、方向、轨迹、接触/受力、反应和环境变化
    - 4.5: 禁止只在 Prompt 末尾汇总对白作为唯一对白信息
    - 4.6: 默认不使用无必要的逐秒拆分

- [x] Task 5: 固化镜头和声音结构
