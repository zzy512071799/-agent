# Wan3 三镜头能力测试规格

## 目标

在正式生成 EP02 全部短镜头之前，先用三个独立测试镜头验证 Wan3 在当前角色资产和调用链路下的关键能力：

1. 表情与身体动作：叶生看见棺内尸身后惊恐、后退半步并停住。
2. 单句对白：闻笙固定近景，完成一句中文台词的口型、发声和克制语气。
3. 消散特效：叶生保持跪姿，从手指边缘开始逐步变成灰雾并伴随铃声。

本阶段只准备配置、校验 Prompt 和 media 映射，不调用 Wan3，不产生视频费用。正式生成必须由用户另行确认。

## 测试镜头

### Probe A：表情与后退动作

- ID：`P01`
- 时长：4 秒
- 模式：`reference`
- 参考图：叶生角色图、旧宅门外棺前场景图
- 主动作：叶生视线从闻笙移向棺内，眉眼出现惊恐，身体向后退半步，最后停住。
- 禁止：对白、复杂运镜、转身、跪下、消散、额外角色进入。
- 验收：眼神方向正确；惊恐表情有明显起止变化；双脚和身体重心完成后退；尾帧姿态稳定。

### Probe B：单句对白

- ID：`P02`
- 时长：5 秒
- 模式：`reference`
- 参考图：闻笙角色图
- 主动作：闻笙固定近景，先吸气，再张口说一句台词，结束后保持平静表情。
- 台词：`你早死了。`
- 禁止：走动、转身、铃响、其他角色说话、镜头大幅运动、字幕。
- 验收：说话者身份正确；台词完整清晰；口型与声音大致同步；语气平静克制；说完后表情和构图稳定。

### Probe C：单一消散动作

- ID：`P03`
- 时长：5 秒
- 模式：`reference`
- 参考图：叶生角色图、旧宅门外棺前场景图、铃道具图
- 主动作：叶生先保持跪姿不动，随后从手指边缘开始出现灰雾，灰雾沿手臂向肩膀扩散，身体轮廓逐渐变薄，铃在最后阶段响一声。
- 禁止：阿离出现、闻笙走动、药箱收纳、对白、瞬间爆炸式消失、镜头切换。
- 验收：消散起点明确；灰雾方向连续；人体轮廓不突然跳变；铃声发生在消散后段；尾帧稳定。

## 技术方案

- 测试镜头单独写入测试配置，不覆盖 EP02 正式 `script.json` 的 `C01-C16`。
- 每个镜头控制在 1 个主要动作、1 个核心表演目标和最多 3 张参考图。
- Prompt 中的 `@图片N` 必须与实际 media 顺序一致，并在动作发生处内联。
- P01、P03 使用场景和角色参考图；P02 只使用闻笙角色图，降低变量数量。
- 测试镜头不继承正式链的上一镜尾帧，避免把连续性问题和能力测试混在一起；如 P03 需要棺前构图，使用场景参考图固定空间关系。
- 测试配置只用于 dry-run 和后续用户确认后的单镜生成，不自动进入正式拼接链。

## 边界与异常

- 不执行正式 Wan3 API 调用，不下载视频，不扣费。
- 图片文件缺失、引用编号越界或网页预览不可用时，测试配置判定为阻塞。
- P02 台词只使用原始短句，不把完整长台词塞入测试。
- P03 不添加阿离和药箱动作，避免把消散能力测试变成多事件测试。
- 测试成功不代表完整 EP02 可直接批量生成；必须逐镜检查并决定是否调整正式 Prompt。
