# 《人间渡》EP02 连续叙事重构任务计划

- [x] Task 1: 盘点并标记现有 EP02 视频素材
    - 1.1: 读取现有 EP02 视频、图片、音频和尾帧文件清单
    - 1.2: 按现实线、功名幻象、人生回闪和消散落点标记现有素材用途
    - 1.3: 标记可直接保留、可作为参考和必须重生成的素材
    - 1.4: 检查每个现有视频的时长、首尾状态、动作逻辑和角色一致性

- [x] Task 2: 重构 EP02 镜头脚本结构
    - 2.1: 将原 5 个 30 秒长镜头拆为约 14-18 个 4-8 秒短镜头
    - 2.2: 按“冷现实相遇→对话→功名幻象→人生回闪→核心提问→消散”重排镜头顺序
    - 2.3: 为每个镜头定义单一主要动作、景别、镜头运动和结束状态
    - 2.4: 建立相遇、对视、看棺材、苦读、咳血、扶棺和消散的动作因果链
    - 2.5: 为每个连续镜头配置上一镜真实尾帧依赖
    - 2.6: 更新 `script.json` 中的镜头 ID、时长、场景、角色和连续性字段

- [x] Task 3: 重写短镜头 Wan3 Prompt 与台词时序
    - 3.1: 为每个短镜头编写只包含一个主要动作的 Wan3 Prompt
    - 3.2: 将角色、场景、道具引用内联到对应出场、接触和特写动作节点
    - 3.3: 统一现实线、功名幻象和人生回闪的色彩与视觉边界
    - 3.4: 为对白配置角色、口型、发声开始点、结束点和对方反应
    - 3.5: 保证每个 `@图片N` 与最终 media 数组顺序闭合
    - 3.6: 保持不加字幕、不加解释性字卡的约束
    - 3.7: 更新台词表或镜头台词映射，保留正确角色归属

- [x] Task 4: 补齐并校验新镜头媒体资产
    - 4.1: 复用通过校验的闻笙、叶生、阿离、药箱和铃素材
    - 4.2: 确认旧宅门外、棺材、灵前、破屋和书桌等场景素材可用
    - 4.3: 为正反打、看棺材、咳血、扶棺、消散等缺失动作补充必要首帧或参考图
    - 4.4: 为所有引用图片生成网页可预览路径
    - 4.5: 校验图片文件存在、引用编号闭合和引用顺序正确

- [ ] Task 5: 按连续链生成短镜头视频（待用户确认后执行）
    - 5.1: 先 dry-run 校验新镜头的 Prompt、media 和依赖
    - 5.2: 按剧本顺序生成现实线与对话镜头
    - 5.3: 抽取每个成功视频的真实尾帧
    - 5.4: 使用真实尾帧继续生成后续功名幻象、回闪和消散镜头
    - 5.5: 失败或缺尾帧时阻断后续镜头，不使用设计首帧伪造连续性
    - 5.6: 逐镜记录 Wan3 任务状态、失败原因和可用性结论

- [ ] Task 6: 重新拼接并对齐音画
    - 6.1: 按叙事顺序拼接片头、现实、对白、幻象、回闪和消散段落
    - 6.2: 按对白表对齐角色发声、口型和反应镜头
    - 6.3: 使用马蹄声、翻页声、灯灭声和铃声建立声音桥接
    - 6.4: 只在进入回闪和消散处使用有叙事意义的水墨转场
    - 6.5: 控制单镜头停留时间，删除无动作、重复和不服务剧情的片段
    - 6.6: 输出新的 EP02 拼接成片并保留可追溯镜头顺序

- [ ] Task 7: 执行成片质量验收
    - 7.1: 逐段检查人物身份、服装、发型和道具一致性
    - 7.2: 逐段检查首尾帧、运动方向、视线和空间连续性
    - 7.3: 检查动作是否具备开始、过程和结果，不接受静态姿势串联
    - 7.4: 检查现实、幻象和回闪的时间层级是否清晰
    - 7.5: 检查对白、口型、声音和反应镜头是否匹配
    - 7.6: 检查片头、消散和铃声片尾是否形成完整情绪落点
    - 7.7: 记录仍需重生成的镜头，不以任务成功代替画面可用性

- [ ] Task 8: 完成工程与文档验证
    - 8.1: 验证 `/api/segments?work=人间渡&episode=ep02` 返回新的镜头顺序
    - 8.2: 验证页面能展示新镜头、Prompt、图片预览和依赖链
    - 8.3: 运行 `npm run typecheck`
    - 8.4: 运行 `npm run build`
    - 8.5: 更新本任务清单完成状态
    - 8.6: 生成 `summary.md`，记录成片结果、质量问题和剩余阻塞
