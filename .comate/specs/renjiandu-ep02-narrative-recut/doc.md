# 《人间渡》EP02 连续叙事重构规格

## 需求场景与目标

现有 80 秒拼接成片由多个 30 秒 Wan3 镜头组成，虽然单帧美术统一，但存在明显的动态插画拼贴感：镜头之间缺少时间、空间、视线和动作因果，红衣功名幻象、闻笙现实线、叶生人生回闪交叉混剪，观众无法明确理解事件顺序。

本次重构目标不是继续修饰现有长镜头，而是把 EP02 改造成可理解的连续叙事：

```text
冷现实相遇 → 对话成立 → 功名幻象 → 人生回闪 → 核心提问 → 消散落点
```

每个视频镜头只承担一个主要动作或一个明确情绪变化，建议单段 4-8 秒；对白拆成可剪辑的正反打；复杂动作拆成起始、过程、结果，所有连续镜头使用真实尾帧承接。

## 叙事结构

### A. 片头与现实建立（约 0-12 秒）

- 单元片头：只显示「叶生」「可曾活过」「第2集」，约 2 秒。
- 旧宅门外建立镜头：冷灰、旧宅、棺材、暮色或阴雨氛围。
- 闻笙与叶生第一次处于同一空间，形成明确视线关系。
- 叶生看见棺材或尸身，表现迟疑、后退或低头确认。
- 铃作为声音和视觉锚点出现，但不抢占叙事。

### B. 对话成立（约 12-28 秒）

- 叶生确认「我……死了？」。
- 闻笙回答「你早死了。你考的那场，是死后的事。」。
- 叶生反驳自己中了功名。
- 闻笙解释「死后的功名」。
- 使用正反打、视线方向匹配、嘴部发声和对方反应；不在对白中切换到无关场景。

### C. 功名幻象（约 28-42 秒）

- 红衣叶生骑马游街、百姓欢呼、红绸和花瓣。
- 这一段完整保持红色高饱和和不真实的喜庆氛围。
- 只做游街和叶生沉浸功名的连续动作，不插入闻笙现实镜头。
- 现有游街素材可作为风格参考和部分素材保留，但必须按运动方向和景别重新剪辑；若动作不成立则拆为短镜头重生成。

### D. 人生回闪（约 42-58 秒）

- 从榜文、红花或墨迹晕开进入回闪。
- 叶生在破屋伏案苦读。
- 翻书、落笔、停顿或咳嗽。
- 灯下继续读写，身体疲惫。
- 咳血、灯灭或画面进入黑白水墨。
- 水墨转场必须服务于“进入回忆/人生结束”，不能作为无因果特效。

### E. 核心提问与消散（约 58-80 秒）

- 回到冷现实，闻笙问：「你现在，还想要这个功名吗？」。
- 闻笙继续问：「你这一生，除了功名，可曾活过？」。
- 叶生愣住、张嘴无答、低头，情绪由执着转为空洞。
- 叶生跪下或扶棺，身体边缘逐渐变淡并消散。
- 铃第一次清晰响，落入旧药箱。
- 阿离探头说：「他走啦？」。
- 闻笙收药箱走入暮色，药箱内铃自行再响作为片尾情绪钩子。

## 技术方案

### 镜头粒度

将原 EP02 的 5 个 30 秒生成段改为多个 4-8 秒视频段。初版建议 14-18 个镜段，具体数量根据对白音频长度和实际素材动作确定：

```text
C01 片头卡
C02 旧宅门外建立
C03 闻笙与叶生同框相遇
C04 叶生看见棺材
C05 叶生确认死亡
C06 闻笙回答
C07 叶生反驳
C08 闻笙解释功名
C09 游街远景
C10 叶生骑马中景
C11 功名幻象近景
C12 榜文/墨迹进入回闪
C13 破屋苦读
C14 翻书落笔与咳嗽
C15 灯灭/水墨收束
C16 闻笙核心提问
C17 叶生无答、扶棺
C18 叶生消散、铃响、阿离反应、闻笙离开
```

实际实施时可把动作明确且连续的相邻镜段合并，但不得恢复成“一个 Prompt 塞入整段剧情”的 30 秒长镜头。

### Wan3 生产约束

- 继续使用 Wan3 `reference` 或适合首尾帧连续性的模式，但每段只描述一个主要动作。
- 每个 `@图片N` 必须对应真实媒体数组顺序，并内联在对应动作句中。
- 连续镜段必须使用上一镜真实输出尾帧；没有真实尾帧时阻断，不使用设计首帧伪造连续性。
- 同场对话镜头固定人物位置、视线方向、光线和背景，不让模型自由改场景。
- Prompt 明确限制角色数量、动作起止、镜头运动和结束状态，避免 4-8 秒内自动编排多个事件。
- 对白写明角色、开始时机、口型和发声结束点，不把对白放入与角色无关的长动作段。
- 不增加字幕，不增加解释性字卡；片头卡只保留单元名、集名和集数。

### 后期拼接

- 根据叙事顺序重新拼接，不按生成完成顺序拼接。
- 先处理画面连续性，再对齐对白、铃声和环境声。
- 使用动作桥接或声音桥接减少硬切：马蹄声可提前进入游街，翻页声可连接回闪，铃声可连接消散。
- 镜头之间避免无目的淡入淡出；只有进入回闪和消散时使用水墨/墨晕等有语义的转场。
- 成片目标时长约 70-90 秒，具体以对白自然停顿和动作完成度为准，不为凑足 80 秒强行拖长镜头。

## 边界条件与异常处理

- 现有视频只有在动作逻辑和连续性可用时保留；美术好但叙事功能不足的片段只能作为参考，不强行保留。
- 如果某个镜段生成失败，不允许用无关镜头顶替；应保持该镜段缺失状态并标注阻断原因。
- 如果真实尾帧缺失，后续镜段不得继续生成。
- 复杂动作出现手部、马腿、药箱、扶棺等结构错误时，以动作逻辑为优先，不以单帧美观掩盖问题。
- 任何新镜头不得引入字幕或解释性文字。
- 最终拼接不得把不同时间状态无标识地交叉剪辑。

## 数据流

```text
新镜头 script.json
  -> /api/segments 返回镜头顺序、Prompt、图片依赖和尾帧依赖
  -> 页面逐镜校验与预览
  -> /api/produce 按镜头顺序生成
  -> 每镜抽取真实尾帧
  -> 下一镜继承上一镜真实尾帧
  -> 按叙事结构、对白时序和声音桥接拼接
  -> 逐段检查人物、动作、视线、空间和情绪落点
```

## 预期结果

- 观众可以明确理解“闻笙在现实中遇到死后的叶生，叶生沉溺于功名幻象，回闪看见自己的一生，最终因闻笙的提问而消散”。
- 单个镜头不再同时承担多个无关动作。
- 对话有正反打和反应镜头，人物关系可见。
- 红色幻象、黑白回闪和冷现实具有明确叙事边界。
- 成片不再主要呈现为静态插画连续变形，而是由连续动作和明确剪辑关系组成。
